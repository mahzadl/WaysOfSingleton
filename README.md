# Ways Of Singleton (Java)

A one-place collection of ways a singleton can be written in Java.

### Context

Singleton is a design pattern. The specific "way" it can be coded by programmers
using in a specific programming language, is here called "idiom".

This collection was created since the initial author found newer
and more interesting idioms with the passing of time, each one with
a valuable insight, especially for new programmers.

Finally, it can also be interesting, for understanding purpose,
in which specific Java-idiom(s) can be expressed the way(s) a more modern
do singletons (for example Kotlin/Scala companion objects,
with/without "lazy" keywords, etc.).

### Disclaimer
The original author has not invented any of these idioms,
so proper credit goes to the original authors (for example
Joshua Bosch and Bill Pugh). Furthermore, these idioms are not guaranteed
to be "production-ready": despite some being useful for understanding,
other solutions (like a framework-provided singleton way) might be safer,
less error-prone, more efficient, more maintainable
and more compatible with the reader's requirement.
